第三章　定積分
3.1　面積與定積分
設函數 f(x) 在閉區間 [a, b] 上連續，將區間 n 等分，在每個小區間取一點作長方形，當 n → ∞ 時，長方形面積總和的極限稱為定積分。
例題 1　求曲線 y = x² 與 x 軸在 0 ≤ x ≤ 1 之間所圍區域的面積。
例題 2　計算 ∫₁² (3x² − 2x) dx。
微積分基本定理：若 F′(x) = f(x)，則 ∫ₐᵇ f(x) dx = F(b) − F(a)。利用這個定理，可以不必計算極限就求出定積分的值。
